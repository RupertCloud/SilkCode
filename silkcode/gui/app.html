How projects work

A session works on exactly one project: the tree its file tools, git commands and test runs are confined to. Open as many sessions as you like, each on its own project and model.

Open or switch project

  • Project cards switch the project this session is on; the conversation comes with you.
  • Add opens a GitHub repository (cloned into ~/.silkcode/projects/), a local directory, or a recently opened project.
  • Terminal: silkcode ~/code/app, or /project inside a REPL session.
  • Opening the same project twice is allowed: the second session is read-only until the first releases the workspace lock.

Create a new project

silkcode new scaffolds a project that already runs and tests, then makes the initial commit. Open it here afterwards with Add.

silkcode new --list
silkcode new todo-cli --template python-cli
silkcode new api --describe "Invoice API for freelancers"
silkcode new api -p "add a health endpoint and a test for it"

Names are normalized ("My New App" → my-new-app). A non-empty directory is refused unless you pass --force; existing files are never overwritten.

Teach the agent about this project

  • SILKCODE.md in the project root: layout, conventions, the test command, anything it should never do. Read on every turn.
  • Repo map: built automatically, so the model knows the codebase before its first tool call.
  • Memory & skills: durable notes and playbooks (/memory, /skills in the REPL).

Verify and ship

  • The agent runs your suite (pytest, npm, cargo, go, flutter) instead of claiming success.
  • Changes shows exactly what changed; Revert undoes a whole turn.
  • Push pushes when you say so; the GitHub dialog can grant pull/commit/push/merge or auto-push.
  • Swarm runs product, design, developer, test and critic agents until it reaches the target.

If something is off

  • Read-only / lock banner: another session holds this project. Close it, or take over once it is idle.
  • The GitHub list is empty: sign in from the GitHub dialog (or silkcode connect github).
  • “no test framework detected”: add a suite and record its command in SILKCODE.md.
  • “no initial commit — empty ident name”: git config --global user.email you@example.com.
